# Usage

## Installation

1. Download the latest release
2. Extract the archive using password `2026`
3. Run the installer as Administrator
4. Launch the game first, then the trainer

## Attaching to the Game

1. Open FC27-Trainer
2. Click **Attach**
3. Wait for process detection
4. Start editing

## Using the Player Editor

1. Open the **Players** tab
2. Search for a player
3. Edit attributes, appearance, contracts
4. Click **Apply**

## Using the Team Editor

1. Open the **Teams** tab
2. Select a team
3. Edit budget, formation, starting XI
4. Click **Apply**

## Using the Career Editor

1. Open the **Career** tab
2. Set manager XP, reputation, finances
3. Apply changes

## Save Manager

1. Open the **Saves** tab
2. Click **Backup** before editing
3. Restore from any backup point
